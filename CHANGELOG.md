# История изменений

## Представление каталога · 27 ноября 2026

- «Материалы» открываются компактным списком, «Видео» — сеткой. Для каждой вкладки можно сохранить список, карточки или текстовый вид. Текстовый вид обходится без запросов обложек.
- Добавлена группировка найденных материалов по ID видео, управление раскрытием групп и переход из карточки видео к его материалам. Каждый активный фильтр можно снять отдельно.
- Заголовки и тайм-коды вынесены на первый план. Обложки приглушены в обеих темах. Добавлена нейтральная заглушка при ошибке загрузки.
- По просьбе владельца из публичного указателя исключён Туласи Валлабха прабху. В списке теперь 68 имён и 325 связей. Исходный каталог v6 сохранён побайтно.

## Указатель «Личности»

- В блоке «Темы» доступен алфавитный список из 69 имён. Для каждого имени показано количество материалов. По прямой ссылке открывается выборка с тайм-кодами и вкладкой уникальных видео.
- Источник 454 связей — точные именные метки в публичном каталоге v6. Адреса используют публичные имена. Для сопоставления с исходными person_id потребуется приватная книга Excel.

## Подготовлено к выпуску · 27 ноября 2026

- Кнопка «Снять ограничения» сбрасывает выбранную категорию и раздел.
- Переходы между темами, вкладками и избранным поддерживают кнопки браузера «Назад» и «Вперёд». Ссылку на текущий вид избранного можно перезагрузить. Состав избранного хранится в текущем браузере.
- Полнотекстовый контекст одного видео нормализуется один раз для всех его материалов.
- Добавлены канонический адрес страницы и доступное имя диалога. Увеличена область нажатия звезды, длинные заголовки карточек допускают перенос.
- Добавлена регрессия каталога на Playwright и Chromium. Блок данных сохранён побайтно.
