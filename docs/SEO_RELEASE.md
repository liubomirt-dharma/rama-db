## Что требует публичного адреса и учётной записи владельца

Среда вернула HTTP 403 при обращении к GitHub Pages, документации Google Search Central и CDN миниатюр YouTube. В локальном снимке используется доступная фирменная обложка, автоматическая сборка на GitHub повторяет загрузку миниатюр. Фактическое воспроизведение YouTube, проверка конечных внешних страниц, внешнее сканирование роботом, актуальный результат Rich Results Test, Schema Markup Validator, Sharing Debugger, PageSpeed Insights и появление ключевых моментов в выдаче здесь не подтверждены.

Владелец выбирает режим Pages, подтверждает доменный префикс в Google и Bing, отправляет sitemap и проверяет карточку публичного выпуска после развёртывания. Код подтверждения выдаёт соответствующая поисковая панель. Инструкции и официальные ссылки приведены в [руководстве](../SEO_GUIDE.md).
