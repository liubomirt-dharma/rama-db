# Передача проекта

Рабочая версия представляет собой статический файл в корне репозитория. В браузере сначала загружается каталог, затем строятся индексы материалов и полных видео. Начальная выдача содержит до 24 карточек. Остальные добавляются кнопкой «Показать ещё». Избранное и тема хранятся в localStorage данного origin. Параметры вида хранятся во фрагменте URL.

## Воспроизведение тестов

Из корня проекта с Python 3 выполните команды ниже. Можно использовать системный Chromium из PATH. При его отсутствии установите совместимую сборку командой `python -m playwright install chromium`.

```sh
python -m venv .venv
. .venv/bin/activate
python -m pip install playwright==1.62.0
python -m unittest discover -s tests -v
```

Набор сам поднимает временный HTTP-сервер и создаёт чистый браузерный контекст для каждого теста. Внешние запросы блокируются для воспроизводимости. Для проверки развёрнутого релиза при доступе к GitHub Pages задайте `RAMA_TEST_URL=https://liubomirt-dharma.github.io/rama-db/` при запуске той же команды. До выкладки исправлений регрессии новой версии могут падать на опубликованной странице.

## После развёртывания

Сверьте контрольную сумму каталога, прогоните тесты на публичном URL и проверьте загрузку обложки и воспроизведение YouTube с ненулевого тайм-кода в браузере с доступом к медиасервису. Для дополнительных источников проверьте конечные страницы после перенаправления. Отдельно зафиксируйте ограничения входа, региона и доступности исходных видео. Итоги локальной проверки и границы сетевого аудита приведены в FINDINGS_LOG.md.
