# Передача проекта

Для развёртывания нужны `index.html` и каталог `assets/` с сохранением относительных путей. В браузере сначала загружается каталог, затем строятся индексы материалов и полных видео. Начальная выдача содержит до 24 карточек. Остальные добавляются кнопкой «Показать ещё». Избранное и тема хранятся в localStorage данного origin. Параметры вида хранятся во фрагменте URL.

## Воспроизведение тестов

Из корня проекта с Python 3 выполните команды ниже. Можно использовать системный Chromium из PATH. При его отсутствии установите совместимую сборку командой `python -m playwright install chromium`.

```sh
python -m venv .venv
. .venv/bin/activate
python -m pip install playwright==1.62.0
python -m unittest discover -s tests -v
```

Набор сам поднимает временный HTTP-сервер и создаёт чистый браузерный контекст для каждого теста. Внешние запросы блокируются для воспроизводимости. Для проверки развёрнутого релиза при доступе к GitHub Pages задайте `RAMA_TEST_URL=https://liubomirt-dharma.github.io/rama-db/` при запуске той же команды. До выкладки исправлений регрессии новой версии могут падать на опубликованной странице.

## После развёртывания

Сверьте контрольную сумму каталога, прогоните тесты на публичном URL и проверьте загрузку обложки и воспроизведение YouTube с ненулевого тайм-кода в браузере с доступом к медиасервису. Для дополнительных источников проверьте конечные страницы после перенаправления. Отдельно зафиксируйте ограничения входа, региона и доступности исходных видео. Итоги локальной проверки и границы сетевого аудита приведены в FINDINGS_LOG.md.

## Виды каталога и группировка

Исходная точка редизайна — коммит `42021a3`. Функция `render` формирует общий отфильтрованный и отсортированный список. Функция `paintResults` отвечает за вид и подгрузку. Для каждой группы используется ID исходного видео. Порядок групп определяется первым совпадением в отсортированной выдаче. Внутри группы материалы упорядочены по секундам, записи без отметки идут последними. Одиночные совпадения показаны отдельными карточками. В плоской выдаче порция составляет 24 материала, в сгруппированной — шесть целых групп.

Режимы для двух вкладок сохраняются под ключами `rama-layout-items` и `rama-layout-videos`, группировка — `rama-group`. В текстовом виде функция карточки пропускает создание изображения. Фрагмент URL `source=VIDEO_ID` открывает материалы исходного видео. Описания берутся из каталога, контекстное совпадение в описании видео помечается отдельно. Список имён служит публичным указателем и может быть уже набора именных меток в исходных данных.

Регрессии для этой версии проверяют URL, тип отображения, состояние фильтров, локальные настройки, сортировку групп, точный состав результатов и отсутствие запросов изображений в текстовом режиме. Для отмены всего релиза используйте обычный revert коммита редизайна.

## Навигация в категории shelling

Блок скрипта `shelling-navigation` в index.html содержит отдельный индекс архивных материалов. Источники географии — именные метки конкретного материала, времени — проверенные заголовки по стабильному ID. В `shellingDates` запись содержит спецификацию даты и дословный фрагмент заголовка. Пример формата диапазона — `2025-12/2026-01`, двух отдельных дней — `2025-06-17,2025-06-20`. Границы месяца и года вычисляются только для сравнения. При пополнении каталога проверяйте совпадение формулировки с первичным источником, идентичность одноимённых населённых пунктов и новые варианты написания. Публичный JSON v6 существует независимо от индекса.

Расширенные элементы относятся к материалам выбранной категории. При переходе к видео, другой категории или избранному их действие прекращается. Hash поддерживает period, year, повторяющийся city, sort и group. Внутри каждой группы сохраняется выбранная сортировка; несколько городов или лет могут ссылаться на один исходный материал. Счётчик выдачи показывает уникальные материалы. Счётчики года учитывают города и наоборот. Выбор нескольких дней одного материала не устанавливает точную привязку каждого города к конкретному дню.

### Повторная сверка дат

В `shellingContextDates` перечислены только вручную проверенные связи с датированной сводкой или другой записью, прямо описывающей те же события. Каждый элемент хранит период, ID проверочной карточки и основание. Для четырёх продолжений ноябрьских обзоров установлен месяц, конкретный день не присваивался. Соседство тайм-кодов или общий год публикации сами по себе недостаточны.

При ревизии публичного экспорта по годам публикации найдены 6 материалов раздела в 6 выпусках 2024 года, 49 в 43 выпусках 2025 года и 34 в 19 выпусках 2026 года. Эти величины описывают публикации. Для сверки оставшихся пропусков с редакционными полями нужен приватный XLSX v6, прежде всего листы «Обстрелы — даты», «Каталог» и «Видео».

### Правило года публикации

По указанию владельца применяем год выпуска как предполагаемый для материалов категории shelling без более надёжной датировки. Приоритет у shellingDates и shellingContextDates. Структурированные дни и месяцы из книги v6, год которых предположителен, перечислены в shellingMonthDays. При отсутствии этих полей используется точность до года. Для многодневных обзоров период относится ко всей сводке. В карточках и группировке по дате выводится основание оценки. Без известного года события и доступной даты видео запись остаётся без года.

Все 89 записей проверены по листам «Обстрелы — даты», «Каталог» и «Видео» приложенной книги. Проверены ID, заголовки, тайм-коды, привязка к видео, даты публикации и все 34 заполненных значения периода в книге (включая предположительные). Для записей с дополнительной датировкой по связанному материалу сохранена ссылка на него.

## Мобильный интерфейс и реестр видео

Маршрут `#mode=videos&sort=new` ведёт в полный каталог. Кнопка в шапке сбрасывает категорию, раздел, источник, имя, период, города, поиск и тип. Маршрут `#cat=mobilization&kind=video` сохраняет тему. Для фильтра по периоду и городам сначала формируется выборка записей архива обстрелов, из неё берутся ID выпусков. Основа обеих выдач — `videoIndex`, построенный по уникальным ключам `vidMap`. Счётчик материалов в краткой карточке исключает служебные главы. Раскрытая карточка и диалог воспроизведения сохраняют полное публичное оглавление.

`videoCard` строит краткую карточку, `recordContent` создаёт содержимое по событию раскрытия. Кнопки общего раскрытия действуют также на следующие порции выдачи. Мобильный указатель тем использует один экземпляр `categoryPanel`, который перемещается в нативный диалог и возвращается после закрытия. Не дублируйте идентификаторы кнопок и полей. Рабочие стили находятся в `assets/library.css`, файлы `kurukshetra-*.webp` имеют разные кадрирования. При замене проверьте лица и положение флага на каждом размере.

Проверки регрессий, контрольные числа и условия измерения скорости приведены в [отчёте](docs/MOBILE_RELEASE.md).
