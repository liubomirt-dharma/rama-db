# Центр изучения варнашрамы «Рама»

Тематическая видеотека лекций и бесед о дхарме, ведической философии и Украине. Статический сайт работает на GitHub Pages.

В разделе «Материалы» доступны компактный список, сетка карточек и текстовый вид без загрузки обложек. Переключатель «Группировать по видео» объединяет результаты текущего поиска. Тайм-код открывает соответствующий фрагмент. Вид и группировка сохраняются в браузере.

В категории «Обстрелы Украины» на вкладке «Материалы» доступны период события и выбор населённых пунктов. Несколько городов объединяются по условию «любой из выбранных». Ссылку на подборку можно скопировать из адресной строки. «Всё время» включает материалы без установленного года.

Если у материала об обстрелах не установлен год события, фильтр учитывает его по году публикации видео. Карточка показывает пометку «предположительный год по публикации видео». Уточнённая дата имеет приоритет.

Кнопка **«Все видео»** открывает весь реестр выпусков, очищает запрос и ограничения и сортирует видео по убыванию даты. Для полных выпусков внутри подборки выберите «Полные видео» в фильтре типов. Раскройте «О выпуске и тайм-коды», чтобы увидеть связанные материалы и источники.

На телефоне поиск, темы и избранное доступны на нижней панели. Кнопка «Фильтры» открывает дополнительные параметры. Выбранные ограничения можно снимать по одному над вкладками результатов.
