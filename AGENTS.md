# Работа с Rama DB

Приложение для GitHub Pages находится в `index.html`. Общедоступный каталог `window.RAMA_DB`, базовые стили и клиентский JavaScript встроены в страницу. Адаптивное оформление и три размера иллюстрации находятся в `assets/`. Для запуска из корня используйте `python -m http.server 8767 --bind 127.0.0.1`.

Сохраняйте идентификаторы видео, материалов и категорий. Они используются в тайм-кодах, ссылках на фильтры и локальном избранном. Изменение классификации требует обоснования и проверки затронутых выборок. В публичном репозитории храните только разрешённые к публикации данные. Для изменения данных документируйте источник и проверьте разницу до обновления контрольной суммы тестов.

Перед PR выполните `python -m unittest discover -s tests -v`. Зависимости и ограничения описаны в HANDOVER.md. Браузерный код должен работать на статическом хостинге. Платные интеграции требуют согласования.
